
# Motion Blur and Image Restoration

**MATH 155 — Homework 5, Problem 1**

## Project Description

This project models image degradation caused
by motion blur and investigates numerical
image restoration using regularized inverse
filtering.

A frequency-domain transfer function is
constructed to simulate motion-induced blur.

The degraded image is reconstructed using
an inverse filter with a regularization
parameter to control numerical instability.

Multiple regularization parameters are
compared using mean squared error.

## Computational Methods

- Frequency-domain degradation models
- Motion blur simulation
- Fourier transforms and inverse FFT
- Regularized inverse filtering
- Mean squared error evaluation
- Regularization parameter comparison
