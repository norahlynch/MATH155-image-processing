
# Spatial Linear Filtering

**MATH 155 — Homework 1, Problem 8**

## Project Description

This project investigates spatial image smoothing
through two-dimensional linear filtering.

Uniform averaging kernels of sizes 3x3 and 9x9
are constructed and applied using MATLAB's
two-dimensional convolution function.

The resulting images are compared to evaluate
the relationship between filter size, spatial
smoothing, and loss of image detail.

## Computational Methods

- Two-dimensional convolution
- Uniform averaging kernels
- Linear spatial filtering
- Spatial neighborhood operations
- Comparative image analysis
