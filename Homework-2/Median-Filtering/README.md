
# Median Filtering for Image Denoising

**MATH 155 — Homework 2, Problem 1**

## Project Description

This project implements a 3x3 median filter
to reduce impulse noise in grayscale images.

The algorithm extracts a local neighborhood
around each pixel, calculates its median
intensity, and assigns this value to the
corresponding output pixel.

Replicated boundary padding is used to
handle image edges.

## Computational Methods

- Nonlinear spatial filtering
- Neighborhood-based image processing
- Median statistics
- Boundary replication
- Impulse noise reduction
