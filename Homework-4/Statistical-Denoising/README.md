
# Statistical Image Denoising

**MATH 155 — Homework 4, Problem 3**

## Project Description

This project compares geometric mean and
alpha-trimmed mean filtering for reducing
noise in grayscale images.

Both filters operate on 3x3 pixel neighborhoods.

The geometric mean computes the geometric
average of neighborhood intensities.

The alpha-trimmed mean removes extreme values
from the neighborhood before averaging.

Filtering performance is evaluated using
signal-to-noise ratio (SNR) measurements.

## Computational Methods

- Geometric mean filtering
- Alpha-trimmed mean filtering
- Neighborhood statistics
- Noise reduction
- Quantitative SNR evaluation
