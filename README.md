
# Mathematical Imaging — MATLAB Projects

**UCLA | MATH 155: Mathematical Imaging**

A collection of computational image-processing projects completed
as part of my undergraduate studies in Physics and Mathematics
at UCLA.

These projects explore the mathematical foundations of digital
image processing, including spatial-domain filtering, Fourier
analysis, image restoration, and tomographic reconstruction.

## Technical Methods

- MATLAB programming and numerical computation
- Histogram equalization and intensity transformations
- Spatial filtering and two-dimensional convolution
- Fourier transforms and frequency-domain filtering
- Statistical image denoising
- Regularized inverse filtering
- Radon transform and filtered backprojection
- Quantitative reconstruction error analysis

## Featured Project: Tomographic Image Reconstruction

Implemented the Radon transform and filtered backprojection
using custom MATLAB functions.

The project generates projection data over 180 angular
orientations and compares reconstructions obtained using
Ram-Lak, Hann, and unfiltered backprojection methods.

Reconstruction performance is evaluated using relative L2
error.

This project illustrates fundamental mathematical methods
underlying computed tomography.
