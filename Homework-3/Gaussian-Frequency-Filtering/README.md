
# Gaussian Frequency-Domain Filtering

**MATH 155 — Homework 3, Problem 3**

## Project Description

This project implements Gaussian low-pass
and high-pass filtering in the frequency domain.

The image is transformed using the two-dimensional
FFT, multiplied by Gaussian transfer functions,
and reconstructed using the inverse FFT.

The two filters are compared to investigate
how different spatial frequency components
contribute to image structure.

## Computational Methods

- Two-dimensional FFT and inverse FFT
- Gaussian frequency response functions
- Low-pass filtering
- High-pass filtering
- Image reconstruction from frequency data
