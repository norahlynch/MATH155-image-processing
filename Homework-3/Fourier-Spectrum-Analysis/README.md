
# Two-Dimensional Fourier Spectrum Analysis

**MATH 155 — Homework 3, Problem 2**

## Project Description

This project investigates the frequency-domain
representation of grayscale images using
the two-dimensional discrete Fourier transform.

MATLAB's fft2() function computes the Fourier
transform, while fftshift() centers the
zero-frequency component.

A logarithmic magnitude transformation is
applied to visualize the frequency spectrum.

The average pixel intensity is also calculated.

## Computational Methods

- Two-dimensional discrete Fourier transforms
- Fast Fourier Transform (FFT)
- Frequency shifting
- Fourier magnitude visualization
- Mean intensity calculations
