# MATH155-image-processing
A collection of computational image-processing projects completed as part of my undergraduate studies in Physics and Mathematics at UCLA.  These projects explore the mathematical foundations of digital image processing, including spatial-domain filtering, Fourier analysis, image restoration, and tomographic reconstruction.
